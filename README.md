# Vignesh Reddy | Portfolio

A personal portfolio website for **R Vignesh Reddy**, a Java Full Stack Developer. It is built with plain **HTML and CSS only**, with no JavaScript, frameworks or build tools.

## Features

- Animated opening screen with a typing effect
- Floating navbar with a gradient logo and a highlight for the section you are viewing
- Dark theme and light theme, switched with a CSS-only toggle
- Scroll-driven animations: reveals, parallax hero and a scroll progress bar
- Custom arrow cursor
- Sections: Home, About, Education, Experience, Projects, Skills, Certifications, Languages and Contact
- Fully responsive layout for desktop, tablet and mobile
- Respects the `prefers-reduced-motion` setting

## Tech

- HTML5
- CSS3 (custom properties, grid, flexbox, scroll-driven animations)
- Google Fonts: Space Grotesk and JetBrains Mono

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/VigneshReddy-25/Portfolio.git
   ```
2. Open the `Portfolio` folder.
3. Open `index.html` in your browser. You can also use the **Live Server** extension in VS Code.

## Browser Support

The scroll-driven animations and the navbar section highlight need a recent version of Chrome, Edge or Safari. In other browsers the site still works, and it simply skips those effects.

## Deployment

The site is static, so it can be hosted for free on GitHub Pages:

1. Go to **Settings → Pages** in the repository.
2. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
3. Save, and the site will be live after a minute or two.
